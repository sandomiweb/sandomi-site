# Sandomi — website

Website of **Sandomi** (სანდომი), a Georgian confectionery producer since 2001.
Three languages — Georgian, English, Russian — B2B catalog with 122 products, order requests, export information, photo gallery and a small browser game.

**Live:** https://sandomiweb.github.io/sandomi-site/ · `/en/` · `/ru/`

## Stack

Static site: plain HTML, CSS and JavaScript (ES modules). No framework, no database and no server code — it runs on any static hosting (GitHub Pages, Cloudflare Pages, Netlify, a regular shared host, nginx).

A small Node build script generates the three language pages from one source template.

## Working on the site

```bash
npm install
npm run build     # src/index.html + data/i18n.json + data/seo.json → language and topic pages, sitemap.xml, robots.txt
npm run serve     # local preview at http://localhost:3000
npm run format    # Prettier
npm test          # browser tests (first time: npx playwright install chromium)
```

The tests open the site on a phone-sized screen and check the main flows: language choice and switching, the home carousel, catalog filters and search, the product dialog and back button, the order form, gallery, map, video, chat assistant, the game, broken images and JavaScript errors. They run offline — outside requests (YouTube, Maps, fonts, FormSubmit) are blocked.

- **Change page text:** edit `src/index.html`, add the English and Russian versions to `data/i18n.json`, run `npm run build`. The build lists any Georgian text that has no translation yet.
- **Change products or prices:** edit `data/products.json` (no build needed). Product photos go to `assets/img/products/`, named after the product in Latin letters (e.g. `vashlis-tqlapi-100g.webp`) — search engines read file names too.
  Products sold by the piece (`unit` other than `kg`) appear in the home-page carousel on phones, in a new random order on each visit; add `"carousel": false` to keep one out (for example, a photo of a plain shipping box).
- **Change the chat assistant:** edit `data/chatbot.json`.
- **Search engines (SEO):** `data/seo.json` holds the home page title and description and the topic pages. Each topic page is the site opened in the catalog view with its own address, title, description, heading, short introduction and product list (a category via `filter`, a word in the product name via `match`, or packed products of some categories), in three languages, with canonical/hreflang tags and schema.org data. Add a page there and run `npm run build`; the category links on the home page point to their topic page and still open in place.
- The site must be opened through a web server (`npm run serve`); ES modules and JSON loading do not work from `file://`.

## Order form

Order requests are sent through [FormSubmit](https://formsubmit.co) to `sandomi.tbilisi@gmail.com` (export: `sandomiproducts@gmail.com`) — see `RECIPIENTS` in `assets/js/order-form.js`.
The first request to each address sends an activation email; click **Activate Form** once. If sending fails, the visitor's email app opens with the filled-in request.

## Going live on sandomi.ge

1. In `site.config.json` set `"baseUrl": "https://sandomi.ge/"` and `"indexable": true`, then `npm run build`.
2. Point the domain to the hosting. Keep the existing **MX records** so `@sandomi.ge` email keeps working.
3. Submit `https://sandomi.ge/sitemap.xml` in Google Search Console.
