# სანდომი — ვებგვერდის კონცეფცია

კონცეფციის პროტოტიპი ახალი sandomi.ge-სთვის. არაოფიციალური ვერსია, ძიებაში დამალულია (noindex).

- `index.html` — მთავარი გვერდი (ქართული / English / Русский)
- `sandomi-tkbili-nakhtomi.html` — თამაში „ტკბილი ნახტომი“
- `img/p/` — პროდუქციის ფოტოები, `img/g/` — გალერეა, `img/h/` — მთავარი ეკრანის შეფუთვები
- `data/sandomi-catalog-2026.csv` — პროდუქციის სია (კატალოგი 2026)
